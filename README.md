# dh-robot：开链机械臂 DH 正向运动学计算

本仓库是一个用 Go 编写的开链机械臂（串联连杆）正向运动学计算库与服务。
给定标准 DH 参数（每个连杆的 a、α、d、θ）以及当前关节角，它可以：

- 计算基座到末端的齐次变换矩阵 T = A₁ A₂ … Aₙ
- 给出每个连杆坐标系原点的三维坐标（骨架折线）
- 计算雅可比、末端速度、工作空间、逆解（平面 2R 肘上/肘下）、奇异性与轨迹

标准 DH 约定（与改良 DH 严格区分）：

```
Aᵢ = RotZ(θᵢ) · TransZ(dᵢ) · TransX(aᵢ) · RotX(αᵢ)
```

## 模块划分

- `internal/dh` — DH 核心：矩阵链乘、坐标系变换、雅可比、动力学、轨迹、工作空间
- `internal/kin` — 正向运动学编排、骨架生成、逆解、可达性校验
- `internal/ik` — 解析逆解（平面 2R）与阻尼伪逆

## 输入 / 输出

核心输入为一组连杆参数（a、α、d、θ）与关节角向量。输出为 4×4 齐次变换、各轴原点坐标、欧拉角（ZYX）、以及骨架折线点列。

## 命令行 / 服务用法

```text
go build ./...
go test ./...
go run . -http :8080
```

启动后访问 http://localhost:8080/ 查看内置页面；API：

- `POST /api/fk`：DH 表 + 关节角向量 → T、各轴原点、欧拉角
- `POST /api/skeleton`：同上 → 连杆折线点列

示例输入：`example/planar-3r.json`（平面 3R，θ 全 0 时末端 x 等于三杆之和）。

## 关键约定

- 角度统一在进入 sin/cos 前完成单位换算；全零角时末端落在伸直位。
- 转动关节用 θ，移动关节用 d，二者不可混用。
- 旋转顺序严格 RotZ → TransZ → TransX → RotX，不可与改良 DH 混淆。
